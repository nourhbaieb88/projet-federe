# Kit video animee (gratuit + efficace)

Stack choisi:
- Generation plans: **Pika Free**
- Montage final: **Clipchamp Free**

Objectif:
- Creer une video promo de 45 secondes pour ton site de reservation.

## Fichiers inclus
- `pika-prompts.md`: prompts scene par scene
- `voiceover-fr.txt`: texte voix-off timecode
- `subtitles-fr.srt`: sous-titres prets a importer
- `edit-plan.md`: plan de montage pas a pas
- `assets/cityreserve-logo.svg`: logo a utiliser dans l'outro
- `assets/cityreserve-logo-v2.svg`: logo v2 (meme theme que le site, alternative)
- `assets/cityreserve-logo-v3-3d.svg`: logo v3 (plus 3D, recommande)

## Production rapide (20-30 min)
1. Ouvre `pika-prompts.md`
2. Genere les 8 scenes dans Pika (une scene = un clip)
3. Exporte chaque clip en MP4
4. Ouvre Clipchamp et importe tous les clips
5. Suis `edit-plan.md`
6. Ajoute la voix-off de `voiceover-fr.txt` (ou IA TTS)
7. Importe `subtitles-fr.srt`
8. Exporte en 1080p

## Personnalisation avant rendu
Le nom de marque est deja pre-rempli: `CityReserve`.
La video est prete pour un usage local avec le message final: `Disponible prochainement`.
